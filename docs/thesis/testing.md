# Перевірки реалізації

## Виконані перевірки

| Команда/сценарій | Результат |
|---|---|
| `python -m ml.training.train` | Успішно; сформовано дві моделі, JSON/CSV та по 4 PNG для кожної. |
| `cd backend; python -m pytest -q` | 5 тестів пройдено; 1 стороннє deprecation-попередження `dateutil`. |
| `cd frontend; npm run build` | Успішно, TypeScript і Vite; попередження про розмір JS chunk. |
| `cd frontend; npm audit --omit=dev` | 0 вразливостей після оновлення пакетів. |
| `docker compose up --build -d` | Успішно: PostgreSQL healthy, backend і frontend running. |
| `alembic upgrade head; alembic check` на чистій SQLite-БД | Успішно; відмінностей між міграцією та ORM-метаданими немає. |
| `docker compose exec -T backend sh -c 'cd /app/backend && alembic check && python -m pytest -q'` | PostgreSQL-міграція без розбіжностей; 5 тестів пройдено у Linux-контейнері, 1 стороннє deprecation-попередження Starlette/AnyIO. |
| `GET http://localhost:8000/health/ready` | HTTP 200, `models.heart=true`, `models.diabetes=true`. |
| `GET http://localhost:5173` | HTTP 200. |
| Наскрізний HTTP-сценарій через PostgreSQL | Логін 200; створення пацієнта, обстеження й показника — 201; дві оцінки — 201; історія містить 2 записи. Повторювана команда: `python -m scripts.smoke_http`. |
| Візуальна перевірка у браузері | Вхід, dashboard з фактичними лічильниками, картка/історія, графіки, порівняння алгоритмів, форма та результат обчислення відображені. |

API-тести перевіряють: відмову без токена, невірний пароль, розмежування ролей; створення пацієнта, обстеження та показника, пошук, dashboard, аудит і видалення; обидва сценарії ML, відповідність відповіді збереженому `joblib`, snapshot та помилку при зайвій ознаці; доступність графіка; створення та вимкнення користувача.

## Наскрізний сценарій

Після `docker compose up --build -d` виконано скрипт через реальний HTTP API і PostgreSQL: вхід `doctor` → синтетичний пацієнт → обстеження → показник → обидва ML-сценарії → історія. Версії у відповідях: `heart-b17cd273da9c-s42`, `diabetes-67594c0f1125-s42`. У браузері виконано додаткову heart-оцінку; UI показав 0,9%, що відповідає API `0.008638624956752723` після округлення. Значення введено на межах дозволених діапазонів виключно для технічної перевірки, не для клінічної інтерпретації.

Скріншотів у `screenshots/` немає, доки вони не будуть отримані із реально запущеного інтерфейсу.
